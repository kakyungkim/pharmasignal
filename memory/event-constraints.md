Agent Forge AI Hackathon Seoul, 2026-08-22 개최. 주제 자유, 13:00~17:00 진행에 제출 마감 15:30. 개인 또는 최대 6명 팀. 상위 6팀 발표 후 최종 3팀 선정, 상금은 스폰서 크레딧 배분.

심사 기준은 **완성도, 혁신성, 실제 문제 해결, 스폰서 제품 활용도** 네 가지다. 파트너는 Bright Data(웹 데이터 수집), Daytona(격리 샌드박스), Nosana(분산 GPU), Qwen Cloud(LLM API)이고, 행사에서 플랫폼 설명은 제공되지 않아 공식 문서로 직접 확인했다.

**Why:** "스폰서 제품 활용도"가 명시된 심사 항목이라는 점이 아키텍처를 결정했다. 네 플랫폼을 억지로 붙이면 어느 것도 안 도는 상태가 되므로, 하나의 파이프라인에서 각자 대체 불가능한 역할을 맡는 구조로 갔다.

**How to apply:** 비슷한 스폰서 해커톤에서 같은 판단을 반복할 것. 심사 기준을 뒤집어 주제의 합격 조건으로 삼는 절차는 [[../.claude/skills/hackathon-sprint/SKILL.md]]에 정리했다. 주제 선택 근거는 [[topic-rationale]] 참조.
