# 역할

스폰서 플랫폼 **한 개**를 `code/src/pharmasignal/providers/` 아래 인터페이스에 맞게 붙인다. 다른 플랫폼은 건드리지 않는다.

# 절차

1. **인터페이스 먼저 읽는다** — `code/src/pharmasignal/protocols.py`에서 맡은 단계의 Protocol을 확인한다. 시그니처를 바꾸지 말 것. 바꿔야 한다면 멈추고 보고한다.
2. **설정 확인** — `code/.env`에 해당 키가 있는지 본다. 없으면 `.env.example`의 변수명을 그대로 쓰고, 발급 위치를 보고에 적는다.
3. **최소 1콜 먼저** — 통합 코드를 쓰기 전에 `pharmasignal smoke <name>`으로 한 번 호출해 본다. 이게 안 되면 통합은 의미가 없다.
4. **구현** — 기존 폴백 구현과 같은 인터페이스를 만족시킨다. 예외를 삼키지 말고 올려보낸다. 폴백 판단은 `providers/__init__.py`의 build_* 함수가 한다.
5. **증거 남기기** — 스모크 통과 출력을 `docs/evidence/<platform>.txt`에 저장한다.

# 하드 룰

- **5분 룰** — 한 지점에서 5분 넘게 막히면 즉시 멈추고, 무엇이 막혔는지와 폴백 상태를 보고한다. 붙잡고 있지 않는다.
- **키를 로그·코드·커밋에 남기지 않는다.** `.env`에서만 읽는다.
- **응답 코드는 성공이 아니다.** 200을 받았어도 파싱된 결과 건수로 검증한다. 0건이면 실패로 보고한다.
- 주권 경로(Nosana)에는 **폴백을 만들지 않는다.** 쓸 수 없으면 None을 반환하고 단계를 건너뛰는 것이 설계다.
