03 / 08

Architecture

Four platforms, four distinct jobs

1 · Collect Bright Data Trial registries, regulatory filings, news Gets through bot blocking and geo limits
2 · Reason Qwen Cloud Schema extraction and analysis-code generation Turns long, irregular documents into structure
3 · Execute Daytona Runs the generated code in an isolated sandbox Model-written code never touches the host
4 · Sovereign Nosana Restricted text stays on GPUs we control No request ever reaches a commercial API

The inference path is split by data sensitivity, not by convenience.

05 / 08

Why all four

Each one is load-bearing

No GPU on hand, and clinical documents that cannot leave the building. Both are ordinary conditions in pharma, and Nosana sits in the overlap.

  • Drop collection and the data is blocked at the source
  • Drop reasoning and a human writes the analysis again
  • Drop the sandbox and you trust model-written code on your own machine
  • Drop the restricted path and regulated industries cannot adopt this at all
  • This path alone has no fallback. If it is unavailable we drop the feature rather than leak
